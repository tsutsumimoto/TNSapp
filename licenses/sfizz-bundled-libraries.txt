Libraries bundled in the sfizz 1.2.2 source tree that ships with ELSE (Source/Audio/sfz~/sfizz/library/external/)
Source: https://github.com/porres/pd-else (tag v1.0-0-rc13)

The ELSE object [sfz~] is built from this tree. Not every library listed here is
necessarily linked into the [sfz~] binary used by TNSapp (for example command-line
tools or demos); they are listed because they are part of the sfizz source tree
from which [sfz~] is built. The license files are reproduced as found upstream.
